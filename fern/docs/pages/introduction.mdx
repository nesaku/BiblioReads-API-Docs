title: Introduction
---

This collection contains the API endpoints for **BiblioReads** (learn more about BiblioReads by visiting the [repo on GitHub](https://github.com/nesaku/BiblioReads)). 

This API provides structured access to book search results, author profiles, series information, reviews, quotes and more via POST requests with a Goodreads URL or identifier in the body.

All `POST` endpoints accept `Content-Type: application/json`. Every endpoint is available at the `/api/*` path of a specified instance. For example, `https://yourinstance.example.com/api/book-scraper`.

**Please note that this is NOT an official API, and could change without notice.**

---

## Endpoints

| Endpoint | Name | Description |
| --- | --- | --- |
| `POST /api/search/books` | search-books | Search for books by keyword using a Goodreads search URL |
| `POST /api/search/lists` | search-lists | Search for Goodreads community lists by keyword using a Goodreads search URL |
| `POST /api/search/quotes` | search-quotes | Search for quotes by keyword using a Goodreads search URL |
| `POST /api/book-scraper` | book-scraper | Get book details for a specific book |
| `POST /api/reviews-scraper` | reviews-scraper | Fetch paginated reviews for a specific book |
| `POST /api/similar-scraper` | similar-scraper | Get similar book recommendations for a specific book |
| `POST /api/series-scraper` | series-scraper | Get all books in a series |
| `POST /api/list-scraper` | list-scraper | Scrape books from a Goodreads community list |
| `POST /api/author/info` | author-info-scraper | Get author profile information |
| `POST /api/author/books` | author-books-scraper | Get all books by a specific author |
| `POST /api/awards/winners-list` | winners-list | Get the list of winners from a Goodreads Choice Awards category |
| `POST /api/awards/winner-page` | winner-page | Get detailed information about a specific Choice Awards winner page |
| `POST /api/quotes/home` | quotes-home | Scrape featured quotes from the Goodreads quotes home page |
| `POST /api/quotes/slug` | quotes-slug | Scrape quotes from a Goodreads quotes tag or slug page |
| `POST /api/works/questions` | questions-scraper | Fetch community Q&A questions for a book |
| `POST /api/works/quotes` | quotes-scraper | Fetch quotes associated with a specific book work |
| `POST /api/works/editions` | editions-scraper | Fetch all available editions of a book work by its Goodreads editions URL |
| `GET /api/status` | status | Check the health status and version of an instance |
| `GET /api/image-proxy` | image-proxy | Proxy a Goodreads or Amazon-hosted cover image, optionally converted to WebP |
